# Text to Speech Converter

A modern, responsive web application that converts text to natural speech in multiple languages.

## Features

- Multi-language support (Bengali, English, Hindi, Urdu, Arabic, and more)
- Adjustable voice controls (speed, pitch, volume)
- Play/Pause/Resume/Stop controls
- Conversion history tracking
- Mobile-friendly responsive design
- No installation required

## Supported Languages

- Bengali (বাংলা)
- English (US & UK)
- Hindi (हिन्दी)
- Urdu (اردو)
- Arabic (العربية)
- Spanish, French, German, Italian
- Japanese, Korean, Chinese

## How to Use

1. Open `index.html` in your web browser
2. Type or paste your text (up to 5000 characters)
3. Select language and voice
4. Adjust speed, pitch, and volume as needed
5. Click "Speak" button

## Browser Support

Works best on:
- Google Chrome (recommended)
- Microsoft Edge
- Safari
- Firefox

## Technologies

- HTML5
- CSS3
- JavaScript
- Web Speech API

## Installation

No installation needed. Simply open `index.html` in a modern web browser.
